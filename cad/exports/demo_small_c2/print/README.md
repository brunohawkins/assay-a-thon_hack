# demo_small_c2 - print bundle

**DEMO SCALE: 30 x 20 mm test article. This is what we can print and emboss today, NOT the device. The design target is the ANSI/SLAS microplate footprint 127.76 x 85.48 mm, 18x this area. Do not read any dimension on these files as the real device.**

Generated by `assay2chip/stages/s11_fabricate.py`. Everything here is in **millimetres**
at the chip-spec origin: (0, 0) is the lower-left corner of the 30 x 20 mm
footprint and z = 0 is the underside of the chip, so the files line up with each other and
with `chip/demo_small_c2.json` without being moved.

| file | what it is |
|---|---|
| `demo_small_c2_body.stl` | the chip itself, 3.3 mm thick, 16 pockets 300 um deep. Resin-print it directly, or treat it as the shape the embossed sheet takes. Channels are **open**: a separate lid or film with drilled ports: the channels in this body are OPEN by design (contracts/blocks.json fabrication_floors.note) |
| `demo_small_c2_mould.stl` | the **positive embossing mould** - a 2 mm plate with the same features raised 300 um. Mirrored in x, so the embossed chip matches the spec seen from the port side. This is the part that goes on the resin printer. |
| `demo_small_c2.dxf` | the cut outline. HEADER declares **$INSUNITS = 4 (mm)**, and every entity is a **closed LWPOLYLINE**; cut the `CUT` layer. |
| `demo_small_c2_fusion_rebuild.py` | Fusion 360 script. Rebuilds both as editable solids (not mesh imports). |
| `render_iso.svg` | isometric view, flat-shaded, scale bar. Depth is exaggerated 1x and the image says so. |
| `render_top.svg` | plan view, true 1:1, chambers and ports labelled, scale bar. |
| `manifest.json` | units, footprint, depth, material, feature count, every check, file hashes, scale. |

## Both STLs were validated before they were written

- **demo_small_c2_body.stl** - 79152 triangles, 1973.988 mm3: watertight, consistent winding, outward normals, bbox is footprint, at spec origin, units mm, height is stackup - all passed.
- **demo_small_c2_mould.stl** - 79152 triangles, 1206.012 mm3: watertight, consistent winding, outward normals, bbox is footprint, at spec origin, units mm, height is stackup - all passed.

A mesh that failed any of these would have raised and left no file.

## Fabrication checks

- PASS `envelope_fits` - 30 x 20 mm against the demo envelope 30 x 20 mm
- PASS `single_etch_depth` - one fluidic layer at one depth: 300 um
- PASS `max_etch_depth` - deepest feature 300 um against the 300 um ceiling
- PASS `min_open_channel` - narrowest cut feature is 'ch_conn_1' at 200 um, floor 200 um
- PASS `min_wall` - thinnest solid wall 400 um (between 'outlet_1_pad' and the edge of the footprint), floor 400 um
- PASS `min_port_bore` - smallest bore 'inlet_1' at 0.8 mm, floor 0.8 mm
- PASS `min_port_pitch` - closest pair inlet_1-reagent_in at 14.37 mm, floor 5 mm
- PASS `port_count` - 4 fluid ports against the demo envelope (30 x 20 mm) limit of 6
- PASS `no_channel_crossings` - no two routed channels cross in plan view
- PASS `port_opens_onto_cut` - every port hole opens onto enough cut channel, chamber or port pad
- PASS `port_reached_by_routed_channel` - every port hole is reached by the channel or chamber the design routes to it
- PASS `features_inside_footprint` - every feature is inside the footprint
- PASS `mould_is_inverse_of_body` - all 19044 cells match: the mould is raised exactly where the body is cut (after un-mirroring in x)
- PASS `geometry_honours_routed_paths` - 4 of 4 channels have an explicit `path`, and every run of it was built; the rest use chip_from_spec's documented automatic route. No channel was drawn as a straight line between its endpoints.
