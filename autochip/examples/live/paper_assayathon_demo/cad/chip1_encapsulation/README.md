# CAD for chip1_encapsulation

Generated by autochip/cad.py from chips/chip1_encapsulation.json (placeholder geometry).

- `chip1_encapsulation.svg`: top view to scale (1 mm grid, bold every 5 mm), modules with id and size, channels at true width, ports (green inlets, red outlets) with id and (x, y)
- `chip1_encapsulation.png`: the same top view as a picture
- `chip1_encapsulation.dxf`: R12 ASCII DXF in mm: OUTLINE, CHAMBERS, CHANNELS (closed outlines at true width), PORTS (circles), LABELS
- `parts/droplets_1.stl`: module droplets_1 placed in chip coordinates (parametric part as a box)
- `chip1_encapsulation.stl`: whole chip: a plain body block plus the fluidic features (chambers, channels, port holes) as separate closed shells in the same file; subtract the features from the block in CAD to get the real part
- `chip1_encapsulation_fluidic.stl`: the fluidic features only (the negative to subtract)
- `chip1_encapsulation_fusion.py`: Fusion 360 script: imports parts/*.stl in place and sketches the outline, ports, channel paths and channel outlines
- `BUILD.md`: step-by-step instructions to redraw the chip by hand in CAD
